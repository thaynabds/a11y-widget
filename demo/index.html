Instalação (1 linha)

<script src="https://cdn.jsdelivr.net/gh/thaynabds/a11y-widget@latest/src/a11y-widget.js" ></script>

Cole antes de </body>. O botão aparece no canto inferior direito. Nenhuma configuração necessária. Preferências salvas no localStorage automaticamente.

Guia de leitura

Ative Guia de leitura no widget e mova o mouse sobre este parágrafo. Uma faixa horizontal acompanhará seu cursor, ajudando a manter o foco na linha que está lendo. Recurso útil para pessoas com dislexia, déficit de atenção (TDAH) ou fadiga ocular.

API JavaScript

// Ler preferências atuais
const prefs = window.A11yWidget.getPrefs();

// Aplicar preferências (ex: carregar do servidor)
window.A11yWidget.applyPrefs({ darkMode: true, fontSize: 2 });

// Falar um texto programaticamente
window.A11yWidget.speak('Bem-vindo ao nosso site!');

// Abrir ou fechar o painel
window.A11yWidget.open();
window.A11yWidget.close();

// Resetar tudo
window.A11yWidget.reset();
